# VynaaValerie — WhatsApp Web TypeScript Library

## Project Overview

**VynaaValerie** is a TypeScript/Node.js library for interacting with the WhatsApp Web API via WebSockets. It provides a clean, modern, event-driven way to build WhatsApp bots and automation without requiring a browser.

## Tech Stack

- **Language**: TypeScript (targeting ES2020/ESNext, ESM)
- **Runtime**: Node.js >= 20.0.0
- **Package Manager**: npm (project uses `packageManager: yarn@4.9.2` in package.json but npm works in this environment)
- **Build Tool**: TypeScript compiler (`tsc`) + `tsc-esm-fix` for ESM compatibility
- **Logging**: Pino
- **Protocol**: WebSockets (`ws`) + Protocol Buffers (`protobufjs`)
- **Encryption**: Signal Protocol via `libsignal`

## Project Layout

```
src/               # Main TypeScript source
  Socket/          # Core WebSocket logic & connection layers
  Signal/          # Signal Protocol encryption
  WABinary/        # Binary encoding/decoding for WA protocol
  Types/           # TypeScript type definitions
  Utils/           # Helper utilities (crypto, auth, media, events)
  WAUSync/         # USync protocol (contact/status sync)
  WAM/             # WhatsApp Metrics encoding
  Defaults/        # Default config values and constants
  __tests__/       # Test suite
WAProto/           # Protobuf definitions + generated JS/TS
Example/           # example.ts — demo usage
lib/               # Compiled output (generated by build)
```

## Setup & Build

```bash
npm install   # installs all deps (runs build automatically via prepare)
npm run build # re-compile manually
```

## Running

```bash
npm run example                            # start example bot (shows QR code)
npm run example -- --use-pairing-code      # use pairing code instead of QR
npm run example -- --do-reply             # auto-reply to messages
```

Auth credentials saved to `vynaa_auth_info/` after first login.

## Key Commands

| Command | Description |
|---------|-------------|
| `npm run build` | Compile TypeScript to `lib/` |
| `npm run example` | Run the example WhatsApp client |
| `npm test` | Run unit tests |
| `npm run test:e2e` | Run end-to-end tests |
| `npm run lint` | Run ESLint |
| `npm run gen:protobuf` | Regenerate protobuf statics |
| `npm run update:version` | Fetch and update latest WA Web version |

## Workflow
